
# Mate a Aula do Tonhão! — Remake

Versão refeita do jogo com:
- visual escuro;
- corredor escolar em **pixel art**, desenhado por código;
- inimigos usando os sprites pixelados gerados;
- menu inicial com PLAY;
- cadastro de nome e turma antes da partida;
- ranking local salvo no navegador.

## Estrutura
- `index.html`
- `styles.css`
- `app.js`
- `assets/tonhao_preto.png`
- `assets/tonhao_verde.png`
- `assets/tonhao_vinho.png`

## Como rodar
Basta abrir `index.html` no navegador.

## Publicar na Vercel
Deixe **todos esses arquivos na raiz do projeto** (ou configure esta pasta como Root Directory).
Framework preset: **Other**
Build command: vazio
Output directory: vazio

## Controles
- Mouse: mirar
- Clique esquerdo: atirar
- R: recarregar
- ESC: pausar
